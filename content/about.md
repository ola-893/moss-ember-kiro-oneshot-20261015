# About this demo

**Moss & Ember is a fictional business.** All addresses, opening hours, prices, and names are invented and should not be relied on for any real purpose.

This site was built to demonstrate [Fission](https://fission.rs) 0.14.1, an open-source Rust UI framework for desktop, mobile, and static web.

- Authored in Rust using the `fission` crate with the `static-site` target
- Three custom widget-based routes: Home, Menu, and Visit
- Deployed to GitHub Pages via GitHub Actions
- No backend, no accounts, no real business

Return to the [home page](/) or browse the [menu](/menu/).
